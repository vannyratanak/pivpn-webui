A .txt file with one rule per line.

File format

kind key=value key=value ...

Blank lines and # comments are skipped. Quote values containing spaces: comment="block guest wifi".

Rule types & examples4 types

Forward Traffic passing through the server

Fields: action, protocol, src, dst, dport, comment

forward action=DROP protocol=tcp src=10.8.0.5 dst=192.168.1.0/24 dport=443

Input Traffic to the server

Fields: action, protocol, src, dport, comment

input action=DROP protocol=tcp dport=22

Port forward

Required: ext_port, target_ip
Optional: target_port, protocol, ext_iface, comment

portforward ext_port=8080 target_ip=10.8.0.5 target_port=80 protocol=tcp

SNAT Source address translation

Required: snat_ip
Optional: src, out_iface, comment

snat src=10.202.226.0/24 snat_ip=192.168.100.12 out_iface=ens19 comment="cluster access"
Variables & advanced syntax
  • Variables. Define CLIENT_IP=10.202.226.21 on its own line, then use src=$CLIENT_IP in rules below it.
  • Client names. Use a client's name instead of its IP for src or dst, for example src=nurak.
  • iptables. You can also paste raw -A FORWARD ... and -A INPUT ... lines. Unsupported lines are skipped.
