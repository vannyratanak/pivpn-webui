Import clients from file

Upload a plain text file to add several clients at once — one client per line.

  • Each line looks like name=laptop-anna — just the client's name.
  • Want the certificate password-protected? Add passphrase=yourpassword after the name.
  • No password needed? Leave passphrase out entirely.
  • If the password itself has spaces, wrap it in quotes: passphrase="correct horse battery staple"
  • Blank lines, and lines starting with #, are skipped — use # to leave yourself notes.

Example file:

name=laptop-anna
name=phone-anna passphrase="correct horse battery staple"
