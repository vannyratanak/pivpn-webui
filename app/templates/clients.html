Renew

This revokes the current cert and issues a new one — the old .ovpn will stop working immediately. Use this to reset a client's forgotten password: there's no way to recover or change the old one, only issue a fresh cert with a new one.

Import VPN clients

Add multiple clients from a plain text file.

A .txt file with one client per line.

File format

name=laptop-anna
name=phone-anna passphrase="your password"

Provide a name for each client. Add an optional passphrase to protect its certificate with a password.

Formatting tips
  • Optional passphrase. Leave out passphrase to create a certificate without a password.
  • Spaces in passwords. Wrap the value in quotes: passphrase="correct horse battery staple".
  • Comments. Blank lines and lines starting with # are skipped.
